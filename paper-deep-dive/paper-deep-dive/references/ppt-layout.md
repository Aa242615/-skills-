## 风格基线：所有场合与样例 PPT 一致

**产物 C 以 `references/group-meeting-sample.pptx` 为主基准**，不论组会、开题、课程 pre 还是答辩都沿用其画布、标题区、校徽位置和整体气质；用户提供的其他样板只用于补充排版经验。样例如下（全量规格见 `references/_sample_spec.txt`）：

- 画布 16:9（13.333 × 7.5"），标题栏约 30pt 加粗 #8E0000（英文 Times New Roman + 中文微软雅黑），标题下细横线，正文 22–24pt（英文 Arial + 中文微软雅黑），图注和来源 16–18pt，强调色 #C00000；
- 右上角每一页放中南大学校徽（含封面）；
- 详细版式与布局规则见 `references/group-meeting-template.md`，做 PPT 前先读它。

## 结构：按汇报节奏而非论文结构组织

论文的顺序是 Introduction → Method → Experiment，**汇报的顺序不一样**。听众在听到方法之前，必须已经知道"为什么需要这个方法"。推荐骨架（页数按 15–20 分钟、约 18 页估算）：

| 页 | 内容 | 要点 |
|---|---|---|
| 1 | 封面 | 见下节 |
| 2 | 汇报大纲 | 4–6 条，让听众知道还有多久 |
| 3 | 背景：这条研究线走到哪了 | 用一个具体场景或痛点开场，不要从定义讲起 |
| 4 | 现有方法的缺口 | 缺口要具体到"贵/慢/不准"这种可感知的程度 |
| 5 | 本文的贡献（1 页讲完） | 3–4 条，每条一句话。**这一页是全篇最重要的**，听众靠它决定后面听不听得进去 |
| 6–7 | 方法总览（1 张总图 + 逐块解释） | 总图放满一页，不要缩小塞在角落 |
| 8–11 | 关键模块逐个展开 | 一页一个模块，公式配符号解释 |
| 12–14 | 实验结果 | 一页一组对比，突出**本文 vs 最强基线** |
| 15 | 消融实验 | 说明每个部件是否真的有用 |
| 16 | 局限与批判 | 作者承认的 + 你的推断（标注「推断」） |
| 17 | 我的思考 / 可延伸方向 | 从产物 E 里挑 2–3 条最扎实的 |
| 18 | 致谢 / Q&A | 留联系方式或引用信息 |

一页一个观点。**如果一页里出现了两个并列主题，拆成两页**——页数上限是死的，但宁可压缩措辞也不要挤信息。

## 白底、图文分区和段落标识

- 页面使用白色背景和深色文字，允许标题使用样例的深红色；禁止“文字+下面色块”、彩色大文本框和文字压在彩色背景上的版式。
- 每页优先使用左文右图、左图右文、上文下图或上图下文。图片和文字大致各占一半，边界留出安全间距；一页只保留一个主观点。
- 使用 PowerPoint 原生项目符号和缩进，最多两级。不要把“1、2、3”直接写进文本；一级要点加粗，二级要点解释证据、例子或限制。
- 正文优先 22–24pt，图注和来源 16–18pt。内容放不下时拆页、缩短句子或改用完整图表，不能靠缩小字号解决。
- 图片、正文和图注不能互相重叠；图注使用独立文本框放在图下方，图片和文字都要保持完整可读。

## 封面硬性要求

用户会明确点名要求，也最容易漏。封面必须包含：

1. **英文原题**（论文原始标题，一字不改）
2. **全部作者**（不要只写一作；作者数很多时写前 3 位 + et al.，并在下一行注明单位）
3. **会议或期刊全称 + 年份**（如 *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR), 2024*）。写缩写时同时给全称。
4. 汇报人 / 单位 / 日期
5. 可选：DOI 或 arXiv 编号，放在底部小字

封面字号明显大于内页，通常是标题 32–40pt、作者 18–20pt、会议 16–18pt。

## 每页校徽（硬性要求）

- **每一页（含封面）都必须有中南大学校徽**，素材固定为 `references/assets/csu-logo.png`。
- 位置统一：右上角 L=10.42" T=0.18" W=2.38" H=0.66"（与样例 PPT 完全一致），所有页面同位置，比例锁定等比缩放，禁止拉伸变形。
- 校徽不能被文本框、图片框、表格压住或遮挡；放完校徽再排其他元素，正文内容区（T≥0.98"）不与校徽相交。
- 用 python-pptx 生成时每页加 `add_picture("references/assets/csu-logo.png", ...)`，路径相对当前 skill 目录解析；交付前用 `check_deck.py` 自动核对每页右上角是否存在校徽。

## 排版数值（16:9，13.333 × 7.5 英寸）

留白比装饰重要。以下是安全区间：

| 元素 | 建议值 |
|---|---|
| 页边距 | 左右 ≥ 0.9"，上下 ≥ 0.7" |
| 页面标题 | 28–32pt 加粗，优先约 30pt，距顶部 0.45" |
| 正文 | 22–24pt |
| 列表行距 | 1.3–1.5 倍 |
| 图注 | 16–18pt，灰色 |
| 一页正文行数 | ≤ 8 行，每行 ≤ 22 个汉字 |
| 项目符号层级 | 最多 2 级 |
| 配色 | 主色 1 个 + 强调色 1 个 + 灰阶。强调色只用来标"本文方法" |

**字号下限 16pt。** 低于这个值投影仪上后排看不见，比页数超标更致命。

## 中文排版的三个坑

1. **中文字体必须单独设置东亚字体**，否则中文会回落到宋体，与英文字体不搭。python-pptx 里要给 run 的 `rPr` 加 `a:ea` 和 `a:cs` 子元素（见下方实操）。
2. **中英混排会撑行高**。英文单词长时会在行中断开，把文本框设成自动换行、并给文本框留 15% 余量。
3. **别用默认的 Office 主题字体**做正式汇报——中文默认落到宋体，观感偏旧。推荐"微软雅黑 / 思源黑体 / 苹方"，英文配 Arial / Calibri / Inter。

## 配图规范（完整优先，禁止截半张图）

- **图片必须完整呈现**：从论文取图必须整张完整（含图注/坐标轴/图例/子图标注），**禁止只截图片的一部分**。最常见的翻车是架构图只截半边、结果图丢了坐标轴——宁可图小一点也要完整。
- **优先抽原图，不要截图**：用 `scripts/extract_pdf.py figures` 抽论文内嵌的原始图片，分辨率远高于屏幕截图。
- **若必须截图**：用 `pages --dpi 300` 渲染整页再裁剪，裁剪框落在图的最外框之外，四周保留至少 0.1" 留白，**不要用 150dpi 以下的图**；截完核对图注、坐标轴、图例一个不缺。
- 图片框必须完整落在画布内（右 ≤ 13.33"，底 ≤ 7.5"），贴边会在大屏/PDF 导出时被裁掉。
- 图片最小宽度 ≈ 页宽的一半；方法总图尽量占满一页。
- 每张图配一行图注，注明来源（图X，出自原文）。
- 自己画的示意图用 matplotlib / Mermaid 生成 PNG，配色与 deck 主色一致。
- **不要拉伸变形**，等比缩放。

## 每页配讲稿备注

每页写 3–5 句口播稿，放进 PPT 的备注栏（speaker notes）。这不是可选项：

- 用户在台上时，备注栏是唯一能救场的东西；
- 写备注的过程会暴露"这页其实没讲清楚"——很多排版问题是写讲稿时才发现的内容问题；
- 备注也是自检依据：讲稿里出现的数字必须在正文页上有对应。

## python-pptx 实操要点

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.oxml.ns import qn

prs = Presentation()
prs.slide_width, prs.slide_height = Inches(13.333), Inches(7.5)  # 16:9

def set_font(run, size, bold=False, color=None, latin="Arial", ea="微软雅黑"):
    f = run.font
    f.size, f.bold = Pt(size), bold
    if color: f.color.rgb = color
    f.name = latin                                   # 西文字体
    rPr = run._r.get_or_add_rPr()
    for tag in ("a:ea", "a:cs"):                     # 东亚字体必须显式设置
        el = rPr.find(qn(tag))
        if el is None:
            el = rPr.makeelement(qn(tag), {}); rPr.append(el)
        el.set("typeface", ea)
```

其他要点：
- 用**空白版式**（`prs.slide_layouts[6]`）自己摆位置，比套模板的占位符更可控；模板占位符经常自带看不出来的缩进和字号。
- **每页先放校徽**（含封面），再排其余元素：`slide.shapes.add_picture(LOGO_PATH, Inches(10.42), Inches(0.18), Inches(2.38), Inches(0.66))`，LOGO_PATH 指向 `references/assets/csu-logo.png`。
- 文本框设 `word_wrap = True`，并手工估算行数确认不溢出——python-pptx 不会自动缩排。
- 备注：`slide.notes_slide.notes_text_frame.text = "..."`。
- 表格用 `shapes.add_table`，表头行给底色，数值列右对齐，**本文方法那一行加粗并着色**。
- 生成后跑 `scripts/check_deck.py`，再**实际打开 PPT 完整目视两遍**——脚本查不出视觉上的拥挤和错位。

## 交付前三轮检查（产物 C 的收尾流程）

1. **脚本检查**：`python scripts/check_deck.py 03_汇报.pptx --report check.md`，ERROR 清零、WARNING 逐条确认（自动查：封面要素、字号下限、东亚字体、图片分辨率、讲稿备注、文本溢出、元素重叠、**每页校徽**、图片越界）。
2. **整体目视**：打开 PPT 完整翻一遍，查整体节奏、拥挤度、文本框压图、图片被页边裁掉、校徽每页都在且位置统一。
3. **逐页对照清单**：

- [ ] 封面：英文原题 / 全部作者 / 会议期刊全称 / 年份，四项齐全
- [ ] 每页（含封面）右上角都有中南大学校徽，无遮挡、不变形
- [ ] 每页只有一个主题，标题即结论；标题栏无副题小字
- [ ] 无文本框溢出、无元素重叠、无被裁掉的图
- [ ] 全文正文字号 ≥ 16pt 且统一；标题 Times New Roman、正文 Arial（中文微软雅黑）
- [ ] 中文字体已显式设置，未回落到宋体
- [ ] 所有图片清晰（≥ 150dpi 等效）、**完整未裁切（含图注/坐标轴/图例）**、比例未变形、有图注和来源
- [ ] 本文方法在所有对比表中视觉上可一眼识别
- [ ] 每页都有讲稿备注，且备注里的数字与页面一致
- [ ] 页码齐全
- [ ] 最后一页写明论文出处，便于听众检索

任何一轮发现问题，改完产物后**从头重跑三轮**；确认全部通过才交付。
