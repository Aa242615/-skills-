# 论文汇报 PPT 版式模板（样例一致，所有汇报场合默认）

> 来源：`references/group-meeting-sample.pptx`（20251222_组会(1).pptx，FENIX: Enabling In-Network DNN Inference with FPGA-Enhanced Programmable Switches，NSDI'26）。
> 全量版式规格见 `references/_sample_spec.txt`（由 `scripts/_dump_sample_spec.py` 提取：几何坐标、字号、字体、层级）。
> 本文件是**所有汇报场合（组会 / 开题 / 课程 pre / 答辩）产物 C 的默认版式规范**：风格、字体、格式必须与样例 PPT 一致。
> 本模板只约束**版式风格**，不约束页数与节奏——按论文内容自然展开，不套固定的页数骨架。

## 什么时候用

- **任何汇报场合都默认套用本模板**（用户提到「组会」更不用说）。
- 系统 / 工程类论文（网络、体系结构、系统、硬件加速等）效果最佳；理论型论文沿用本模板的版式数值，内容结构按论文实际情况组织。
- 本模板定义**版式与风格**，内容仍来自论文精读产物，不许编造。

## 风格要点（照着这份 PPT 的气质做，不是照着页数做）

- **标题即主题，不做总结**：每页标题栏只放页面主题（如 `Motivations & Challenges`、`Data Engine  FlowTracker`），**不要**在标题下面再挂一行小字总结（如 `FPGA网内推理优势、挑战及目标`）。总结是讲的时候说的，不是印在 PPT 上的。
- **一页一个模块**：组件页一页一个组件；系统总览一页一张架构图 + 组件要点；实现一页平台、一页配置；评估按「对比方案 / 数据集 / 结果」分组。
- **图表说话**：能用图说明的不要写长句子；图占页面主体，文字是陪衬。
- **减少不必要的输出**：只保留听众必须看到的；标题栏副题、重复性的过渡句、原文大段引用都属于噪音，一律删。

## 三种内容页布局（来自样例）

1. **左文右图**：要点列表占左侧（L=0.64 起），架构图/示意图放右侧，图下配一行图注。
2. **上要点下图**：组件要点在上（4–6 条），系统图占页面下部。
3. **双图对比**：两张结果图并排（如左"交换机资源使用率"、右"FPGA 资源使用情况"），每张图上方/下方有 20pt 加粗小标题。

## 段落与图文分区

- 每个并列要点使用 PowerPoint 原生项目符号，左缩进约 0.25–0.35 英寸、悬挂缩进约 0.15–0.20 英寸，最多两级。
- 不使用“1、2、3”作为视觉列表，也不把序号手工写入正文字符串；一级要点加粗，二级要点解释证据、例子或限制。
- 页面保持白底，文字使用深色；允许样例的深红标题和细分隔线，禁止文字压在彩色块上或在文字下铺大色块。
- 优先选择左文右图、左图右文、上文下图或上图下文，图片和文字大致各占一半。文字、图片、图注之间必须留出安全间距，不能交叉重叠。
- 图片应尽量使用完整原图；图注单独放在图片下方，不占用图片内容区。

## 每页校徽规则（硬性要求）

- **每一页都必须有中南大学校徽，包括封面。** 素材固定用 `references/assets/csu-logo.png`（蓝白校徽+校名组合，396×110px）。
- 位置：所有页面统一放右上角（L=10.42" T=0.18" W=2.38" H=0.66"），比例锁定不变形（等比缩放，禁拉伸）。
- 校徽不可被任何文字框、图片框、表格压住或遮挡；它在上层，正文内容区（T≥0.98"）不与它相交。
- 校徽放完后再放其他元素，检查时确认每页右上角都有且清晰。
- 不得用其他图片冒充校徽；样例右上角的正是中南大学校徽，直接用同一素材。

## 字体与对齐规则（实践教训：先检查，再交付）

- 标题一律 **Times New Roman（英文）+ 微软雅黑（中文）**；正文 **Arial（英文）+ 微软雅黑（中文）**。
- 中文必须显式设置东亚字体（python-pptx 加 `a:ea` / `a:cs`，见 `ppt-layout.md` 实操），否则中文回落宋体、与英文字体错位。
- 全文正文字号统一 20pt，**不低于 16pt**；同一页内同类文字字号、字体必须一致。
- **字体对齐检查（每页必做）**：
  - 中英混排的行高不一致会导致文字上下错位——给文本框设统一行距（1.3–1.5 倍），不要依赖默认行高；
  - 同段内中英文字体基线要对齐：英文 Arial 与中文微软雅黑混排时，检查是否出现英文略高/略低；
  - 所有文本框左对齐、垂直居中的设置全页统一，不要有的靠上有的居中；
  - 换行后不得出现孤行（一个词单独成行）。
- 一页内最多两级项目符号，避免层级越多越难对齐。

## 配图规则（实践教训：完整优先，禁止截半张图）

- **图片必须完整**：从论文取图必须整张图完整呈现（含图注/坐标轴/图例/子图标注），**禁止只截取图片的一部分**——实践中最常见的翻车是架构图只截了半边、结果图丢了坐标轴。宁可图小一点也要完整。
- **截图 = 整张完整图**：若必须用截图（而非抽原图），用 `scripts/extract_pdf.py pages --dpi 300` 渲染整页后裁剪，四周保留至少 0.1" 的留白边，确保没有任何像素被裁掉；裁剪框必须落在图的最外框之外。
- **优先抽原图，不要截图**：用 `scripts/extract_pdf.py figures` 抽取论文内嵌的原始图片（分辨率远高于屏幕截图），抽不到时再用整页渲染，**不要用 150dpi 以下的图**。
- 每张图配一行图注，注明来源（图X，出自原文）；图注放图**下方独立文本框**。

## 布局规则（实践教训：文字与图片互不侵犯）

- **小字/图注不能与图片重叠**：文本框与图片框不允许相交——图注放图下方独立一行（图底边与图注文本框顶边至少留 0.1"），页面标题、正文、图注都与图片保持间距。
- 图片与文字框的边界不相交：生成后用 `scripts/check_deck.py` 检查元素重叠，再实际打开 PPT 目视确认每个文本框都没有压在图上。
- **图片不能越出页面**：任何图片框必须完整落在画布内（右 ≤ 13.33"，底 ≤ 7.5"），贴边会在大屏/PDF 导出时被裁掉。
- 文本框设 `word_wrap = True` 并预留 15% 余量，防止溢出撞到图片或页边。

## 使用步骤

1. 参数收集中确认汇报场合（任何场合都按本模板）→ 在第二步「一页纸大纲」里说明将按样例模板排版。
2. 生成产物 C 前先打开 `references/group-meeting-sample.pptx` 参考版式（或查 `references/_sample_spec.txt`），按本文件的数值与风格制作 `03_汇报.pptx`（页数按内容自然展开，不套固定骨架）。
3. **先把校徽放到每一页右上角**（含封面），再排标题栏、横线、正文与图片。
4. 字体对齐、图片完整、文字图片不重叠、校徽不遮挡四项按上文逐页检查。
5. 生成后按「三轮检查」交付：`scripts/check_deck.py` → 整体目视一遍 → 逐页对照清单一遍；发现问题改完重跑三轮。

## 复用注意

- 模板的「内容」全部替换为当前论文的材料；封面四项（英文原题 / 全部作者 / 会议期刊全称 / 年份）不许缺。
- 用户指定其他汇报场合（开题 / 答辩 / 课程 pre）时，版式数值与风格**仍然复用本模板**——风格、字体、格式始终与样例一致。
- 原始规格（每页坐标/字号全量 dump）见 `references/_sample_spec.txt`；如需重新提取：`python scripts/_dump_sample_spec.py`。
